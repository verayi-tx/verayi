# Verayi

Personal website for Verayi.

This is a static site: open `index.html` directly or deploy the repository to GitHub Pages, Vercel, Netlify, or any static host.

## Edit Content

Most section content lives in `script.js`:

- `favorites`
- `workingOn`
- `done`
- `notes`

The main intro and navigation live in `index.html`. The visual system lives in `styles.css`.
